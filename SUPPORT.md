# Support

TaskFocus is an actively developed personal project. Support is provided on a best-effort basis; there is no hosted public demo or guaranteed response time.

## Where to ask

- For a reproducible defect, [open a bug report](https://github.com/Simifar/taskfocus/issues/new?template=bug_report.yml).
- To propose a change, [open a feature request](https://github.com/Simifar/taskfocus/issues/new?template=feature_request.yml).
- For setup trouble, first check [`docs/SETUP.md`](docs/SETUP.md) and search existing [issues](https://github.com/Simifar/taskfocus/issues).
- For a suspected security vulnerability, follow [`SECURITY.md`](SECURITY.md). Do not put vulnerability details in a public issue.

Please include the steps needed to reproduce a non-security bug, the expected and actual result, and relevant sanitized logs. Never post passwords, tokens, database connection strings, personal data, or production records.

## Current scope

The interface is Russian-only. Password reset and email delivery are not implemented. The project does not currently provide team workspaces, a hosted demo, or an automated authenticated browser/E2E suite.
