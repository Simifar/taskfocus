# TaskFocus · Brand Kit 1.0

Выбранный концепт: **06 / 12 «Следующий шаг» (Интерфейсный характер)**. Исходная геометрия сохранена без редизайна. Готовая идентичность для веб-приложения, PWA и потенциальных нативных оболочек.

## Начните здесь

- `08_Brandbook/index.html`: визуальный брендбук; открывается офлайн, изображения берутся из папок рядом.
- `01_Masters`: два исходных SVG с канонической геометрией и машинописный JSON мастер-параметров.
- `02_Logos/SVG`: 16 комбинаций символа, горизонтального/вертикального логотипа и слова, включая светлые и монохромные.
- `02_Logos/PNG`: растровые логотипы на прозрачном фоне, полезны для презентаций.
- `03_App_Icons`: квадратные, маскируемые, прозрачные, светлые, одноцветные, Android/iOS source SVG и PNG.
- `04_Web_and_PWA`: фавикон, apple touch icon, 192/512, maskable 192/512 и готовый manifest.
- `05_Native`: опциональные Android / iOS / Windows exports, в том числе `Android/res/` и готовый iOS `AppIcon.appiconset`. Нативные проекты не менялись автоматически.
- `06_Social`: OG, Twitter/X, квадратная карточка, 2 splash-шаблона.
- `07_Implementation`: CSS/JSON design tokens, разметка head, образец Android adaptive icon XML.

## Правила размера и композиции

- Канонический символ: viewBox `0 0 120 120`; три исходных path без трансформации относительных пропорций.
- Защитное поле прозрачного символа: минимум `0.2×` его видимого габарита до соседнего элемента (x = высота знака).
- Минимальный размер: 24 px для полноцветного символа на прозрачном фоне, 16 px только для подготовленного квадратного favicon.
- Горизонтальная подпись: ориентир минимум 120 px ширины для четкости слова; использовать крупнее в навигации.
- Не добавлять вручную тени, градиенты или растяжение. Не поворачивать знак ради декора.
- На тёмных поверхностях использовать файлы `*-inverse.svg`; на светлых — `*-primary.svg`.
- Не применяйте `#5278F6` для мелкого текста на белом без дополнительной проверки контраста; токен `#3156CA` предназначен для таких случаев.
- На платформенных app icons скругление делает ОС — **не задавайте готовые углы для iOS AppIcon-1024, PWA и Android**; `rounded-corners-mockup-only.svg` исключительно для показа.

## Web/PWA установка

1. Скопируйте содержимое `04_Web_and_PWA/` в каталог `public/` приложения, не нарушая относительные пути `icons/`.
2. Добавьте из `07_Implementation/head-snippet.html` нужные теги в `<head>`.
3. Проверьте `start_url`, `scope`, `id`, если приложение живёт не в корне домена. Манифест намеренно использует относительные пути.
4. Для OG положите файл `06_Social/og-image-1200x630.png` в `public/og-image.png` и замените `YOUR-DOMAIN.EXAMPLE` действительным доменом.
5. Проверьте PWA на HTTPS или localhost; картинки не заменяют service worker и остальную PWA конфигурацию.

## Android, iOS

- Android adaptive icon: **готовая папка `05_Native/Android/res/` с vector drawables и adaptive-icon XML**; исходники слоёв `03_App_Icons/SVG/android-...`, растры `05_Native/Android/` 432 px = 108 dp при 4x; 66 dp safe-circle соблюдён через масштабирование символа и центрирование. Образцы XML из `07_Implementation/` — шаблоны, пути ресурсов адаптируйте под конкретный Gradle-проект.
- iOS: `05_Native/iOS/AppIcon-1024.png` — квадратный непрозрачный 1024 px без скругления; дополнительные 180, 167, 152 для web/mobile интеграций. Для Xcode требуется положить исходник в asset catalog с настройками проекта.
- Android monochrome: одноцветный foreground предоставлен как SVG и PNG, но итоговое системное тонирование зависит от версии Android/launcher.
- Splash: PNG-шаблоны. Нативные launch screens / устройства / PWA splash формируются отдельно системой; не объявляйте эти две картинки полным набором всех разрешений.
