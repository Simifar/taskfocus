# Security policy

## Supported code

Security fixes are considered for the current `main` branch. The repository has no published releases or supported version branches at this time.

## Reporting a vulnerability

I could not confirm that GitHub's private vulnerability reporting form is enabled for this repository. Please **do not** publish exploit details, credentials, personal data, or a proof of concept in a public issue, pull request, or discussion.

If you find a suspected vulnerability, open a [minimal issue](https://github.com/Simifar/taskfocus/issues/new) asking the maintainer for a private reporting channel. Do not include technical details in that issue. Share the report only after a private channel has been provided. If GitHub private vulnerability reporting is enabled later, use the repository's **Security → Advisories → Report a vulnerability** form instead.

This project is maintained on a best-effort basis. No response-time or remediation-time guarantee is offered. Please allow maintainers a reasonable opportunity to investigate and coordinate a fix before any public disclosure.

## Secret handling

Never submit `.env` files, tokens, passwords, real database URLs, or real user data. Use sanitized logs and disposable test data in public reports.
